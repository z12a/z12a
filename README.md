### 你好 👋 I'm ZHAO MY
一个网络工程专业的学生，应该毕业了吧。目前没有个人博客key，所以没有b'key。还没有找到工作。你可以看看我的个人技能，也可以作为你的学习方向。🎉 有趣的事实
编程语言：我最喜欢的编程语言是 Python，因为它简洁优雅，就像写诗一样。
咖啡因依赖：没有咖啡的早晨，代码就像没有灵魂的躯壳 ☕。
键盘侠：我的键盘是我最好的朋友，每天敲击它超过 10,000 次。
Bug 猎人：我擅长在代码中找到隐藏的 Bug，就像福尔摩斯破案一样 🕵️‍♂️。
🚀 我的目标
开源贡献：希望未来能为更多开源项目贡献代码，成为社区的一员。
全栈大师：目标是成为一名全栈开发工程师，前后端通吃！
技术博客：计划创建一个个人博客，分享我的学习笔记和技术心得。
🌟 我的座右铭
代码如诗：写代码就像写诗，每一行都要优雅而富有意义。
永不放弃：遇到 Bug 不要怕，调试是程序员的基本功。
持续学习：技术更新太快，只有不断学习才能不被淘汰。
🎮 我的爱好
游戏：<img src="https://img.shields.io/badge/steam-%23000000.svg?style=for-the-badge&logo=steam&logoColor=white" alt="Steam" />

运动：偶尔打打篮球，放松身心，保持健康。
📚 推荐学习资源
书籍：

网站：
LeetCode：刷题必备，提升算法能力。

🤔 如果你问我...

如何找到工作：多投简历，多面试，积累经验，不要放弃。
如何保持动力：设定小目标，完成一个就奖励自己，保持积极心态。
